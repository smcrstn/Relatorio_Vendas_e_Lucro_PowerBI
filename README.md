# Dashboard de Vendas e Lucro - Power BI

## Descrição do Projeto

Projeto desenvolvido durante o desafio prático da DIO com foco em análise de dados e construção de dashboards no Power BI.

O objetivo foi explorar recursos de visualização de dados, segmentação, KPIs e análise de vendas utilizando a base Financial Sample.

---

## Recursos Utilizados

* Power BI
* Segmentação de dados
* KPIs
* Gráficos de barras
* Gráfico de pizza
* Mapas geográficos
* Interações entre visuais
* Filtros por período

---

## Indicadores Analisados

* Soma de vendas
* Lucro por país
* Volume de vendas
* Unidades vendidas
* Evolução mensal do lucro
* Distribuição de lucro por segmento

---

## Estrutura do Relatório

### Página 1

Análise geral de vendas por produto e segmento.

### Página 2

Análise de vendas considerando países e lucro.

### Página 3

Análise geográfica utilizando mapas no Power BI.
